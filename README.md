# GradePro - Student Grade Management System

A simple website to manage student grades built with HTML, CSS and JavaScript.

## What it does
- Add, edit and delete students
- Enter marks for 8 subjects
- View percentage and grade reports
- Grade calculator
- Data is saved in browser (localStorage)

## Pages
- Home - Manage Students
- Enter Marks
- Percentage Report
- Grade Report
- Grade Calculator
- Java Backend Code

## How to Run
1. Download the zip file
2. Extract the folder
3. Open index.html in your browser
4. No server needed!

## Grading Scale
- A+ = 90 to 100% (Outstanding)
- A  = 80 to 89%  (Excellent)
- B  = 70 to 79%  (Very Good)
- C  = 60 to 69%  (Good)
- D  = 40 to 59%  (Average)
- F  = 0  to 39%  (Fail)

## Tech Used
- HTML5
- CSS3
- JavaScript
- localStorage
